# Runtime issue tracker

Investigation started 2026-10-19. Every observed issue is recorded here, including limitations that remain open. Generated reports and captures are under `out/reports`; game assets and saves remain excluded from Git.

| WIN-001 | Fixed with startup resolution policy | Resizing changes the window but breaks the game's viewport / input alignment. | Render resolution is now selectable instead of hardcoded to 1280 x 720. Native mode uses actual client pixels after applying Windowed/Maximized/Fullscreen, before game initialization. Custom mode uses the selected resolution. That Android surface remains stable for the session; presentation and touch share an aspect-fit viewport. See WIN-007 for the live reconfiguration limit. |
| WIN-002 | Fixed | Windows ghosting is enabled during long guest calls. | `DisableProcessWindowsGhosting` runs before SDL creates a window. New long-loading sessions retained their normal window instead of the DWM ghost encountered in the baseline. This does not remove synchronous loading stalls. |

| COMPAT-003 | Fixed | Offline network stubs use incorrect return types / bionic error constants. | DNS returned a negative non-bionic EAI value; pointer-returning inet_ntop could return an invalid all-ones pointer. DNS now returns EAI_NONAME 8 with a null result. Numeric IP conversion is implemented locally; pointer failures return null. Disabled transport remains ENETUNREACH. Contract tests pass. |
| COMPAT-004 | Fixed | Canonical path output can contain Windows separators. | The new independent NDK regression caught realpath returning a backslash-prefixed path. Normalized guest realpath/cwd now use forward slashes and never expose a host drive path. Native and host tests pass. |
| COMPAT-005 | Fixed | Android long double is incompatible with the Windows CRT type; %Lf raised an exception. | Added exact integer-ratio conversion and binary128 SIMD returns/storage; decimal and hexadecimal formatting supports actual quad arguments. The NDK fixture verifies the 113th precision bit, full-width scanf and printf, and mixed register/stack arguments. |
| COMPAT-006 | Fixed | PROT_NONE mappings cannot regain access; retired translations can survive mapping changes. | Keep a committed-page marker separate from rwx bits. Reprotect/remap tests preserve inaccessible data and restore access. Remap/shrink/unmap invalidate retired guest translations. |
| COMPAT-007 | Fixed | Stream lifetime and error contracts are incomplete. | Closing invalidates all opaque handles and frees owned handle allocations; fdopen shares descriptor ownership. Shared lookahead supports fscanf and UTF-8 wide pushback. Invalid fflush reports EBADF, ftruncate reports -1/errno, fsync commits the descriptor, and exclusive create preserves existing data. |
| COMPAT-008 | Documented boundary | Optional POSIX modes remain unsupported. | Fixed/writable shared mappings, file-backed mapping growth, partial mapping changes, append-mode changes on existing CRT descriptors, alternate numeric locales and allocating/positional scanf extensions return explicit errors or remain outside the documented contract. F_GETLK reports unknown peer pid -1 conservatively. These are listed in `offline-compatibility.md`; do not claim full POSIX support. |
| ONLINE-001 | Disabled by design / audited | Online and unrelated bindings lacked a complete suppression inventory. | Added registered suppression policies, exact signatures, behavior and per-session call counts, plus per-library native import resolution status. Network, HTTP, billing, ads, analytics delivery, Google Play and unrelated process/device APIs are reported in `suppressed-functions.md`. Local persistence and cleanup remain implemented. |
| COMPAT-009 | Fixed during follow-up review | Directory metadata lost traversal bits; sendfile permitted a self-copy; a contended lock coordinator could wait indefinitely. | Directory stat now preserves 0755 traversal bits, self-copy returns EINVAL, and nonblocking lock operations return EAGAIN when their cross-process coordinator is busy. Blocking waits check shutdown and worker failure. Added directory-stat coverage to the offline suite. |
| COMPAT-010 | Draw-call quota fixed / 14,665-frame regression passed | A sustained gameplay session stops on the guest instruction budget. | The original stop after 25,168 frames is preserved in `out/reports/followup-original-crash.json`: PC `0x32268b0`, LR `0x1c824f8`, last import `free`, no unresolved imports or worker faults. The stack includes recursive native UI traversal and resource lookups; `free` is not established as the cause. Draw callbacks now use a 60-second deadline without the arbitrary 2-billion-instruction cutoff. Instruction quotas and deadlines are independent; pthread lifetime calls explicitly opt out of both while retaining cancellation. A failing-before/passing-after regression covers the former timeout bypass; finite quotas, cancellation and fault context are tested. The combined game run exits normally at 14,665 frames without faults. The exact original input sequence was not recorded, so that sequence is not reproduced. |
| AUDIO-002 | Fixed / media reads verified; effects and music confirmed by user | Many game sounds are missing or play only briefly, including Crazy Dave (the gardener) and Penny (the truck) speaking. | Wwise opens streamed media with Android mode `r`. Passing that directly to the Windows CRT selected text translation and Ctrl-Z EOF. Android file streams now always use binary host mode, including write/append. Actual media reads formerly returned only 138 of 8,427 bytes, 1,427 of 10,408 and 991 of 65,536; binary reads match all original bytes. Real-game voice events and streaming reads are traced in `stream-probe-after.log`; byte comparisons are in `media-byte-validation.json`. The user confirmed effects and music worked well in the final run and that they closed the application themselves. Existing focus deduplication and multi-engine ownership fixes are retained. |

## Validation sessions
