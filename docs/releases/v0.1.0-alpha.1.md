# Android PC Runtime / PVZ2 v0.1.0-alpha.1

This is the first experimental Windows x64 prerelease. It runs original ARM64 Android native code through Dynarmic and supplies Windows implementations of the Android services used by the PVZ2 adapter. Broader game compatibility and release qualification remain in progress.

## Downloads

- `pvz2pc-v0.1.0-alpha.1-windows-x64.zip`: portable Release build, including the launcher, game, console tools, ANGLE graphics DLLs, app-local MSVC DLLs, documentation and dependency licenses.
- `pvz2pc-v0.1.0-alpha.1-source.zip`: the tracked project source at the release commit. GitHub also provides its standard source ZIP and tar.gz archives. Building downloads the dependencies declared in `cmake/Dependencies.cmake`.
- `SHA256SUMS.txt`: SHA-256 hashes for the two named ZIP files. Use `Get-FileHash -Algorithm SHA256` in PowerShell to compare a download.

Game APKs, OBBs, native game libraries, saves, profiles and personal launcher settings are excluded.

## Windows setup

1. Extract the entire Windows ZIP into a writable folder on a Windows x64 PC. Keep its `angle`, `docs` and `licenses` directories with the executables.
2. Install the Microsoft Edge WebView2 Evergreen Runtime if it is not already installed; HTML consent dialogs require it.
3. Import your own matching APK and OBB. For the tested PVZ2 version, use version 13.5.1 / versionCode 1063:

   ```powershell
   .\pvz2pc.exe import --root '.\runtime' --apk 'C:\Games\com.ea.game.pvz2_row.apk' --obb 'C:\Games\main.1063.com.ea.game.pvz2_row.obb'
   ```

4. Open `pvz2pc-launcher.exe`, select the imported runtime folder, configure display/audio settings, then choose **Save & Play**. Settings are written to `launcher.json` beside the executables.

The game requires its original content. Other versions and games need separate compatibility validation. See the included README for split APKs and optional Android external data import.

## Included behavior and validation boundary

- Native Windows launcher, console diagnostics and a game executable without a console window.
- Startup render resolution selection, aspect-preserving desktop resizing and touch mapping, fullscreen toggling, audio focus handling and separate local save profiles.
- Implementations for the 27 formerly unresolved native imports in the supplied version, with offline compatibility tests and runtime suppression reports.
- Prior documented gameplay checks restored Adventure and exercised the Ancient Egypt Day 3 tutorial and its HUD. They do not establish level completion or compatibility across all worlds.

The release is built with the pinned MSVC 19.51.36257.0 toolchain in Release mode. The release preparation runs all seven CTest suites, including the independent ARM64 Android test application, and checks the installed Windows package. Detailed historical evidence and open issues are in [implementation status](../status.md), [issues](../issues.md) and the [offline audit](../offline-compatibility.md).

## Known limitations

- A local gameplay session stopped after 25,168 frames with `Guest instruction budget exceeded` at PC `0x32268b0` (last recorded import: `free`). No unresolved imports or worker errors were reported. The root cause is unconfirmed; this prerelease does not resolve that sustained-session failure.
- Long synchronous guest loading can delay window input.
- Change render resolution in the launcher and relaunch; live resizing changes presentation while retaining the startup render resolution.
- Online transport, Google Play Games, purchases, advertising and analytics delivery are disabled. Purchases return unavailable responses.
- Sustained gameplay, broader world/API coverage and physical audio quality remain unqualified. Some launcher resize behavior still needs a visual recheck.

Source builds require Visual Studio's C++ desktop tools, the pinned MSVC toolset, CMake and Git; follow the repository README. The project includes an AI assistance disclosure and third-party notices.
